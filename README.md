# プログラミング基礎チュートリアル (with Claude Code)

初心者向けに、Pythonでプログラミングの基礎を学びながら、Claude Codeの使い方も身につけるための学習用リポジトリです。

## 進め方

- `lessons/` の中に、レッスンごとのフォルダがあります。
- 各レッスンには `README.md`(説明・課題)と、練習用のコードファイルがあります。
- 1レッスンずつ、実際にコードを書いて動かしながら進めます。
