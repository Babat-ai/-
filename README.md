# Claude Code 使い方コース

Claude Codeを実戦形式で使いながら、その機能・操作方法を身につけるための学習用リポジトリです。

## 進め方

「自己紹介ページ(Webページ)」を実際に作りながら、以下を同時に学びます。
- HTML/CSS/JSがそれぞれ何をしているか(作りながら都度説明)
- Claude Codeが裏で何のツールをどう使っているか

コードを書いたら、その都度「これは何をしているコードか」を解説します。わからない部分はいつでも聞いてください。
