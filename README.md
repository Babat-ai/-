# Claude Code 使い方コース

Claude Codeを実戦形式で使いながら、その機能・操作方法を身につけるための学習用リポジトリです。

## 進め方

- チャットで指示を出し、私(Claude Code)が実際にツールを使って動く様子を見ながら学びます
- `guide/` の中に、各レッスンのメモや練習の記録を残していきます

- [x] 00. Hello World (準備運動、コミット/プッシュの流れを体験)

- [ ] 02. ファイル操作(読む・書く・編集する)
- [ ] 03. コード検索(Grep / Glob)で既存コードを探す
- [ ] 04. コマンド実行(Bash)とその安全性
- [ ] 05. Gitワークフロー(status / diff / commit / push)
- [ ] 06. Planモード(大きめの変更を計画してから実行)
- [ ] 07. スラッシュコマンド・スキルの活用

- [ ] 10. 実践: 小さな機能をゼロから作ってPRを作成する
